# Documentation

`Project-II-report.pdf` is the full project report submitted at Óbuda
University: biometric security fundamentals, facial recognition principles,
the experimental build, and the conclusion.

The original appendix (source-code screenshots) has been removed from this
copy, because it contained live Wi-Fi credentials. The complete sketch lives
in `firmware/esp32cam_face_access/` instead, with the credentials replaced by
placeholders.

`images/` holds photographs of the assembled system.
